# Framed

An interactive wall-layout planner that helps users visualize picture-frame arrangements before hanging them.

## What it demonstrates

- Canvas-based interaction using Konva.js.
- Controls for wall dimensions, background textures, and common frame sizes.
- A visual approach to a practical layout problem.

## Technologies

JavaScript, Konva.js, jQuery, jQuery UI, HTML, and CSS.

## Explore the project

[Demo](https://framed.jasontylerrodriguez.com)

Open `index.html` in a browser to explore locally. Some dependencies are loaded from external CDNs.

- `assets/js/script.js`: application behavior.
- `assets/css/main.css`: application styling.
- `assets/css/img/`: wall textures.

## Background and status

Originally developed as a college portfolio project. Preserved as an example of interactive frontend and canvas work. The code and bundled libraries reflect the original implementation; compatibility with current browsers has not been comprehensively validated.

Pull requests are not currently accepted; feedback is welcome.
